# Repository instructions

- Keep the installable Skill under `skills/evolve-software-architecture/` concise and free of repository-maintenance documents.
- Keep facts, inferences, unknowns, and constraints distinct in Skill instructions and evaluation rubrics.
- Add project-specific observations to an evaluation case before promoting them into a core reference.
- Run `python3 scripts/validate-skill.py` before committing changes to the Skill.
- Use `feat/`, `fix/`, or `chore/` branches and Conventional Commits; keep `main` releasable.
- Release the upstream Skill before synchronizing a project copy.
