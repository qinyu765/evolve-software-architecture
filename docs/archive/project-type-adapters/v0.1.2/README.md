# Archived project-type guidance

These two files are byte-for-byte copies from the annotated `v0.1.2` release:

- `desktop-tauri.md` — the former built-in desktop/Tauri adapter.
- `project-type-selection.md` — the former adapter selection and expansion policy.

They are retained as historical evidence, outside the installable package. They are no longer maintained or loaded by the Skill. v0.2.0 uses a general architecture workflow and available technology Skills; when suitable Skills are missing, users choose whether to use official documentation, supply a Skill, or narrow the task. See [ADR-0004](../../../adr/0004-generic-core-and-companion-skills.md).
